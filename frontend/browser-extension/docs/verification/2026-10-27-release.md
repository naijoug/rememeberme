## Fixes found during acceptance

- An instruction-like model input initially yielded an invalid response. JSON output mode and explicit schema guidance fixed the observed sample without relaxing validation; all eight synthetic live cases then passed. See [backend release](../../../../backend/docs/verification/2026-10-27-context-release.md).
- The installed disclosure's Enable/Cancel labels were adjacent. `ContextExplanation.vue` scoped CSS was outside the closed ShadowRoot. Styles now live in the shared inline `paper-sage.css`; the final live ZIP test checks actual button-box separation of at least 11px.
- Release smoke previously assumed all public lookup calls were POST. The enabled capability GET is now checked as bodyless while word POST body assertions remain strict.

## Published privacy and remaining boundaries

The new personal `/privacy` returned the exact effective 0.1.5 asset. Local request archiving/OTLP status and metadata-only usage fields were inspected; upstream zero retention is not promised. Personal account verification, resource IDs and rollback paths are in the backend release record. No company-account, old-domain or DNS write was used.

Mac/iOS candidate accessibility and physical signing are separate from this Chrome release. This run does not prove universal model quality, indefinite network availability, Chrome Web Store review, or actual VoiceOver speech. Physical-device acceptance remains conditional on an explicitly authorized signing team.
