Remember Me for macOS 0.2.0

- Check for Updates is available in the RememberMe menu and Settings → Updates.
- New versions can be downloaded, verified and installed inside the app.
- Automatic checks are enabled by default. Automatic download and installation are optional.
- Update archives and the update feed must pass signature verification before installation.
- GitHub sign-in opens account words and enables sync. Account, General and Privacy settings are organized into separate tabs.
- Existing vocabulary, account credentials and explicit sync pauses are retained.

This personal distribution supports macOS 14 or later on Apple silicon and Intel.
The app uses ad-hoc code signing and is not notarized. Its update archives and
feed are authenticated with the dedicated Remember Me Ed25519 signing key.
