# Magpie translation deployment

Date: 2026-10-24 (America/Los_Angeles). Source base: `581dea7` plus the
Magpie implementation in the working tree. The user authorized implementation,
client compatibility, testing and deployment to the existing personal server.

## Deployed behavior

Remember Me now calls the same-host Magpie 0.1.1330 gateway directly at
`http://127.0.0.1:3425/v1/chat/completions`, with model
`zhipu/glm-5.3-flash`. The loopback app label is `magpie-rememberme`; vendor
credentials remain in Magpie. The API never uses its web-administration key.

The primary has a twelve-second deadline, two-request concurrency limit,
256-token output budget, 64 KiB response limit and strict finished-text JSON
validation. Requests carry one word and the translation instruction, with no
tools, sessions, contexts or source URLs. Provider timeout/busy/invalid-response
and unavailable errors retain the four-second MyMemory fallback. Server caches
hold at most 1,000 successful translations; Magpie/Hermes live for seven days,
MyMemory fallback for one hour. `TRANSLATION_PROVIDER=hermes` remains available
for rollback; the old isolated Hermes service and credentials were retained.

The public/authenticated routes and request bodies are unchanged. Responses
identify the actual `magpie` or `mymemory` source. `translation-source-v3` and
the three accepted sources are advertised; legacy Hermes/MyMemory histories
remain valid. Shared validators, browser storage/import/export, Swift decoding,
source labels and cache handling were updated. Extension 0.1.2 uses `public:v3:`;
connected native lookup uses `backend-v3:` and a twenty-second deadline.
